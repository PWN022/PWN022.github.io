# 工作组

将不同的计算机按照功能分别列入不同的工作组。想要访问某个部门的资源，只要在"网络"里面双击该部门的工作组名。工作组就像一个可以自由进入和退出的社团，方便同组的计算机相互访问，工作组没有集中管理作用，工作组里的计算机都是相互对等的（即没有服务器和客户机之分）。对局域网中的计算机进行分类，使得网络更有序。计算机的管理依然是各自为政，所有计算机依然是对等的，松散会员制，可以随意加入和退出，且不同工作组之间的共享资源可以相互访问。

# 内网域

组织架构分类：单域、子域、父域、域树、域森林、DNS域名、邮件服务器等。

"域"是一个有安全边界的计算机组合（一个域中的用户无法访问另一个域中的资源），域内资源由一台域控制器（Domain Controller，DC）集中管理，用户名和密码是放在域控制器去验证的。

优点：通过组策略来统一管理。

## 单域

即只有一个域的环境，一般需两台DC，一台DC，一台备用DC（容灾）

## 父子域

类比公司总部和公司分部的关系，总部的域称为父域，各分部的域称为该域的子域。使用父子域的好处：
- 减小了域之间信息交互的压力（域内信息交互不压缩，域间信息交互可压缩）
- 不同的子域可以指定特定的安全策略

父子域中域名使用一个.表示一个层次，类似于DNS域名表示方式，子域只能使用父域的名字作为域名后缀

## 域树

多个域通过建立信任关系组成的集合。若两个域之间需要相互访问，需要建立信任关系（Trust Relation），通过信任关系可以将父子域连接成树状结构

## 域森林

多个域树通过建立信任关系组成的集合。

## 域名服务器

实现域名到IP地址的转换。由于域中计算机使用DNS来定位DC、服务器和其他计算机的，所以域的名字就是DNS域的名字。

内网渗透中，大都是通过寻找DNS服务器来确定域控制器位置（因为DNS服务器和域控制器通常配置在一台机器上）

# AD域（Active Directory Domain）

AD域服务（AD DS）的基本管理单元，指共享同一目录数据库、安全策略与信任边界的网络对象（用户、计算机、服务器、打印机等）集合。

核心本质：安全边界 + 认证中心 + 策略根。默认 “拒绝一切访问”，仅显式授权才可访问资源。

- 核心组件：

1、**域控制器（DC）**：运行AD DS的服务器，存储目录数据库（Ntds.dit），处理所有域内认证、授权与策略下发。

2、**成员服务器/计算机**：加入域的Windows设备，登录与权限由DC统一管控。

3、**组织单元（OU）**：域内容器，用于按部门/职能分层管理对象、GPO策略。

- 核心价值（内网场景）：

1、**统一身份认证（SSO）**：域账号登录任意域内设备，访问所有授权资源。

2、**集中安全管控**：通过组策略（GPO）统一配置密码复杂度、锁屏、软件白名单、补丁强制安装。

3、**精细化权限分配**：基于用户/组/OU，为文件、打印机、应用分配最小权限。

4、**资产统一管理**：内网所有Windows电脑、服务器、在AD中可查可控可审计。

# 域内权限

域本地组：来自全林作用于本域

全局组：来自本域作用于全林

通用组：来自全林作用于全林

```
- 域本地组：
- 多域用户访问单域资源
- （访问同一个域），主要用于授予本域内资源的访问权限，可以从任何域中添加用户账号、通用组和全局组。域本地组无法嵌套在其他组中
```

```
- 全局组：
- 单域用户访问多域资源
- （必须是同一个域中的用户），只能在创建该全局组的域中添加用户和全局组，但可以在域森林中的任何域内指派权限，也可以嵌套在其他组中
```

```
- 通用组：多域用户访问多域资源，成员信息不保存在域控制器中，而是保存在全局编录（GC）中，任何变化都会导致全林复制
```

## 本地域组的权限

```
Administrators（管理员组） ————最重要的权限

Remote Desktop Users（远程登录组）

Print Operators（打印机操作员组）

Account Operators（帐号操作员组）

Server Operaters（服务器操作员组）

Backup Operators（备份操作员组）
```

## 全局组、通用组的权限

```
Domain Admins（域管理员组）————最最最重要的权限，域渗透是看重这个

Enterprise Admins（企业系统管理员组）————最重要的权限，其次这个Schema Admins（架构管理员组）————最重要的权限

Domain Users（域用户组)
```

## A-G-DL-P策略

```
A：用户账户

G：全局组

DL：域本地组

P：许可，资源权限
```

# 域环境安全

信息收集：了解当前网络架构和权限分布

权限提升：将当前控制权限提升解决限制

代理隧道：解决内网域中出网和通讯限制

横向移动：利用漏洞和口令等扩大后续战果

权限维持：植入后门或票据等进行后续控制

防护突破：堡垒机/杀毒AV/EDR/HIDS等

# 实际场景

单域：中小企业内网首选，简单稳定。

父子域/域树：中大型企业、多部门/地域，需策略隔离。

域林：集团、并购场景，最高级安全与架构边界。

# 单域环境搭建

## 设备环境

三台机器，分别是Win10 PC、WinServer 2016 DC、WinServer 2016 Webserver

## 准备工作：虚拟机提前安装搭建及网卡分配

**关闭防火墙**并改计算机名，计算机网络配置静态IP和DNS

虚拟网卡的子网地址为：192.168.20.0，子网掩码255.255.255.0

### **PC**

计算器名字改为：pc

手工分配ip为：192.168.20.20，子网掩码255.255.255.0，默认网关192.168.20.1

DNS服务器为：192.168.20.22

本地账户：administrator/bound2

域内账户：bdsec/admin!@#45

### **DC**

计算器名字改为：dc

手工分配ip为：192.168.20.22，子网掩码255.255.255.0，默认网关192.168.20.1

DNS服务器为：192.168.20.22

本地账户：administrator/bound2

域内账户：webserver/admin!@#45

### **Webserver**

计算器名字改为：webserver

手工分配ip为：192.168.20.21，子网掩码255.255.255.0，默认网关192.168.20.1

DNS服务器为：192.168.20.22

本地账户：administrator/bound2.com

## 安装工作

DC安装域控和DNS服务，提升到DC域控配置域名

在DC上，配置此服务器->添加角色和功能->直接下一步到服务器角色->选择Active Directory域服务->下一步到安装

安装完成之后，在仪表板会有一个旗帜图标点击之后有个名为**将此服务器提升为域控制器**的选项

添加新林，根域名根据情况（bound2.com）->域控制器选项会有一个目录服务还原模式的密码设置，根据需求即可->下一步到“其他选项”会分配 **NetBIOS 名称**。默认会根据根域名第一段生成，例如 `bound2.com` → `BOUND2`，可修改也可不修改。它是**域的 NetBIOS 名称**，主要用于旧版兼容，以及 `DOMAIN\用户名` 这种登录格式中的 `DOMAIN` 部分。用户登录名仍然是域用户账户名，UPN 登录则是 `用户名@bound2.com`->下一步到安装

## 加入工作

DC上添加域内用户，修改主机名称及使用其他的机器加入域

### DC

AD DS栏->DC的Active Directory用户和计算机->点开域名Users->新建用户

**PC**的域内账户名：bdsec，登录名：bdsec，密码如上，且设置为永不过期

**Webserver**的域内账户名：webserver，登录名：webserver，密码如上，且设置为永不过期

---

回到PC/Webserver本机

### PC

此电脑->属性->更改设置->隶属于域->bound2.com->输入DC配置好的域内账户名与密码


### Webserver

此电脑->属性->更改设置->隶属于域->bound2.com->输入DC配置好的域内账户名与密码
